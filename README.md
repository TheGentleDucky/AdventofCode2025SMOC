# Advent of Code 2025

My solutions for [Advent of Code 2025](https://adventofcode.com/2025), written in **Java**.

This repository was created to later present in my oral exam for the subject Ingeniería del Software 2, so wish me luck I suppose.

## Programmed with

* Java
* Maven
* JUnit
* IntelliJ IDEA

## Project structure

Each Advent of Code day is organized into its own package, with separate solutions for each part of the challenge.

```text
src/
└── main/
    ├── java/
    │   └── adventofcode2025smoc/
    │       ├── FileProcessor.java
    │       ├── day1/
    │             ├── part1
    │             ├── part2
    │       ├── day2/
    │       ├── day3/
    │       ├── ...
    │       └── day12/
    │
    └── resources/
        ├── D1_Input.txt
        ├── D2_Input.txt
        ├── ...
        └── D12_Input.txt
```

Common functionality is kept separate when it is shared between both parts of a day.

## Approach

The solutions are developed with a focus on:

* Clean and readable Java code
* Single Responsibility Principle (SRP)
* SOLID principles where they make sense
* Small and focused classes and methods
* Immutability where appropriate
* Using records when they provide a simple representation of data
* Choosing straightforward algorithms before reaching for unnecessary complexity


##  Advent of Code

[Advent of Code](https://adventofcode.com/) is an annual collection of programming puzzles released throughout December.

Each day contains two parts. The second part usually builds upon the first one and often requires changing or improving the initial approach.
